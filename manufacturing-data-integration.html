SYSTECH SOLUTIONS · AUG 2023–SEP 2025

Manufacturing Data Integration

Data integration workflows consolidating data from multiple ERP systems into Azure SQL staging and reporting tables, including data modelling, basic reporting and a ticket-tracking report for Managed Services.

Azure Data FactoryAzure SQLSQLPower AutomateData ModellingReporting

Business problem

A manufacturing client needed scheduled movement of data from multiple ERP systems into a centralized Azure SQL environment for downstream reporting and analytics.

My responsibilities

  • Developed ADF pipelines to extract data from multiple ERP systems using a combination of pipeline activities.
  • Loaded source data into Azure SQL staging tables.
  • Developed SQL transformations using joins, CTEs, dynamic SQL and stored procedures.
  • Designed a structured data model to support reporting requirements.
  • Created a basic ticket-tracking report for the Managed Services team.
  • Implemented basic validation checks.
  • Configured Power Automate email notifications for unsuccessful pipeline executions.

Design decisions

  • Separated staging and reporting layers to isolate ingestion from reporting transformations.
  • Used ADF to orchestrate extraction from multiple ERP systems.

Data quality

  • Implemented basic validation checks during ingestion.
  • Performed basic checks on loaded data before downstream reporting.

Error handling and monitoring

  • Power Automate email notifications for unsuccessful ADF executions.
  • Pipeline failures required manual investigation; no automated rerun process is claimed.

Performance

Developed SQL transformations using joins, CTEs, dynamic SQL and stored procedures. No indexing changes or measured query-performance improvements are claimed.

Version Control

Used Git for source-code version control. No CI/CD pipeline is claimed for this project.

Outcome

  • Established a multi-ERP integration workflow into Azure SQL reporting tables.
  • Created a structured reporting data model and a basic ticket-tracking report for Managed Services.
  • Improved visibility into pipeline failures through automated email notifications.

What I learned

Separating ingestion and reporting logic improves maintainability. Failure alerts provide visibility, while recovery still requires investigation and a defined rerun process.
